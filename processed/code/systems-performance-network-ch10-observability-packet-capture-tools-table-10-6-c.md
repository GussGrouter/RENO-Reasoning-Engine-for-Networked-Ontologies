## Summary

- Packet capture is the highest-fidelity end of the ladder: useful when you need **wire-level truth** (headers/options/timing) that counters/traces cannot supply.
- The text groups **CLI sniffer** and **GUI inspection** as the same class: powerful, expensive, and easy to overuse under load.
