# Systems Performance — Ch.10 §10.3.2 Protocols

Source: `systems-performance-ch10-scout-p520-640.txt`, lines **1037–1055** (PDF 520–640 extract; scout rebuilt 2026-04-20).

## Summary

- Protocol standards enable communication, but **protocol choice** and **version** (e.g., IPv4 vs IPv6) can change code paths and performance.
- Protocol behavior can be shifted by tunables (buffers, algorithms, timers).
- Protocols use encapsulation, so overhead and behavior accrue across layers.
