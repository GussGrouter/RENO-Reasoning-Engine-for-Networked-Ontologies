FileBench
FileBench is a programmable file system benchmark tool, where application workloads can be
simulated by describing them in its Workload Model Language. This allows threads with different behaviors to be simulated, and for synchronous thread behavior to be specified. It ships
with a variety of these configurations, called personalities, including one to simulate the Oracle
database I/O model. Unfortunately, FileBench is not an easy tool to learn and use, and may be of
interest only to those working on file systems full-time.
