# Systems Performance — Ch.10 §10.4.1 Protocols (IP: DSCP/ECN)

Source: `systems-performance-ch10-scout-p520-640.txt`, lines **2149–2186** (PDF 520–640 extract; scout rebuilt 2026-04-20).

## Summary

- IP headers include fields for traffic treatment: **DSCP** (service class / drop probability behavior) and **ECN** (explicit congestion signaling).
- ECN can provide congestion avoidance benefits without relying on packet drops, if correctly supported end-to-end.
