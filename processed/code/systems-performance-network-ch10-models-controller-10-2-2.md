# Systems Performance — Ch.10 §10.2.2 Controller (NIC) (model)

Source: `systems-performance-ch10-scout-p520-640.txt`, lines **939–956** (PDF 520–640 extract; scout rebuilt 2026-04-20).

## Summary

- A NIC provides ports and contains a **controller** (microprocessor) that moves packets between ports and the system I/O transport.
- The controller can be on an expansion card, integrated on the board, or via other transports (e.g., USB).
