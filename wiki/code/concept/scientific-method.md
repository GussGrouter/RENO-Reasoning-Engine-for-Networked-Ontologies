# Scientific method

- Tag: abstraction

## Definition

The **scientific method** structures performance investigation as hypothesis-driven work:

- question (problem statement)
- hypothesis
- prediction
- test (observational or experimental)
- analysis

## Relation

- Role: framework (hypothesis-driven reasoning structure that selects tests and updates beliefs).
- The question is often established via [[problem-statement-method]].
- Tests can be observational vs experimental (see [[observability-vs-experimentation]]).
- Iteration converts [[known-unknowns-framework]] into checked hypotheses by measuring or experimenting quickly, discarding bad theories early.
- This fits the workflow in [[model-classify-intervene]] as a disciplined way to move from model and classification to evidence-backed intervention.
- When multiple tools can measure the “same” quantity, **independent cross-checks** (different code paths, different frameworks) are a practical way to test the “test” when results are business-critical or implausible.
