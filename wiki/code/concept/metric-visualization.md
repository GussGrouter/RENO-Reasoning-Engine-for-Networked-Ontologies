# Metric visualization

- Tag: heuristic

## Definition

**Metric visualization** is the practice of plotting performance data to enable pattern recognition, correlation discovery across metric sources, and inspection of distributions that are hard to infer from text summaries alone.

## Relation

- Role: method (a repeatable way to turn raw series/events into interpretable structure).
- Line charts emphasize trends over time; scatter plots can reveal per-event structure and outliers (pairs naturally with [[latency-percentiles]] and [[latency-outliers]]).
- Fits [[model-classify-intervene]] by making hidden structure visible before choosing interventions.
