# Diagnosis cycle

- Tag: heuristic

## Definition

The **diagnosis cycle** iterates quickly between a hypothesis and data collection:

\[
\\text{hypothesis} \\rightarrow \\text{instrumentation} \\rightarrow \\text{data} \\rightarrow \\text{hypothesis}
\]

## Relation

- Role: cycle (a short iteration loop inside broader methods like [[scientific-method]]).
- A lightweight restatement of [[scientific-method]] emphasizing fast feedback from data.
- Instrumentation choice and availability determines which hypotheses can be tested (see [[known-unknowns-framework]] and [[instrumentation-overhead-and-perturbation]]).
- Fits the workflow in [[model-classify-intervene]] by forcing early evidence collection and rapid hypothesis updates.
