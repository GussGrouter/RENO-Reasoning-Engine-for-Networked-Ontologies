# Time–space tradeoff

- Tag: tradeoff

## Definition

A **time–space tradeoff** exchanges resource usage (space/area/memory) for speed (time/latency), or vice versa.

## Scope note

In implementations, “space” often means chip area/transistor count, memory capacity, or additional parallel structures; “time” often means critical-path delay or per-item processing latency.

## Relation

- A common design axis for implementation work; applies to both software and hardware.
- Supports reasoning in [[network-algorithmics]] about exploiting available resources to meet timing constraints.
