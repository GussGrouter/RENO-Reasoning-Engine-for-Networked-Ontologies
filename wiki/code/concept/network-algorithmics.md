# Network algorithmics

- Tag: structure

## Definition

An **interdisciplinary systems approach** to improving the performance of an implementation by combining methods from algorithms, systems, and hardware-aware design.

## Core properties

- **Interdisciplinary**: combines techniques from algorithms, architecture, operating systems, and hardware design.
- **Systems-oriented**: achieves efficiency by reallocating work across components (e.g., where/when work is done) while preserving behavior.

## Relation

Often applied to diagnose and remove **implementation bottlenecks** (as distinct from pure resource limits). See [[resource-vs-implementation-bottleneck]].

Effective application depends on observability signals (counters/events) that expose the relevant implementation work.
