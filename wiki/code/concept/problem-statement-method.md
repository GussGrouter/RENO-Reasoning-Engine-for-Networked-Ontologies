# Problem statement method

- Tag: heuristic

## Definition

The **problem statement method** is an initial performance-analysis routine that clarifies the problem by asking structured questions (symptom, history, recent changes, metric expression, scope/impact, and environment details).

## Relation

- Role: method (front-door checklist to frame the question before deeper analysis).
- Helps choose appropriate metrics and framing (e.g., express as [[throughput-latency-metrics]]).
- “What changed?” and environment questions support early separation of load/architecture/resource hypotheses (see [[resource-vs-implementation-bottleneck]]).
- Can reduce wasted work by turning ambiguity into concrete [[known-unknowns-framework]] items to check.
