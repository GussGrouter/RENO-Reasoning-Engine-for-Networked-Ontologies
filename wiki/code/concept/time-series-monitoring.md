# Time-series monitoring

- Tag: measurement

## Definition

**Time-series monitoring** records performance statistics over time so past behavior can be compared to the present, peaks and growth can be quantified, and “normal” context can be established for current readings.

## Relation

- Role: measurement (a longitudinal signal collection discipline, not a single metric).
- Complements [[baseline-statistics]] (explicit baselines) and [[counters-statistics-metrics]] (what gets recorded and aggregated).
- Supports [[model-classify-intervene]] by turning “is this unusual?” into evidence-backed classification using historical ranges and patterns.
