# RENO Agent Policy Navigation

This directory splits the monolithic root `AGENTS.md` into focused instruction files. This README is navigational only. It is not policy authority; if it conflicts with root `AGENTS.md`, a phase file, a policy file, or a template file, this README loses.

Start with root `AGENTS.md`, then read only the subfiles needed for the current task.

## Phases

- `phases/phase-0-boundary-map.md`: book/source boundary mapping before body ingestion.
- `phases/phase-1-parse-chunk-spine.md`: raw registration, parser output, chunk construction, manifests, and chunk spine work.
- `phases/phase-2-source-extraction.md`: bounded source-shaped memory and candidate ideas.
- `phases/phase-3-reasoning-ontology.md`: concepts, insights, contradiction synthesis, and ontology maintenance.

## Policies

- `policy/authority-model.md`: authority layers, role model, and knowledge-layer semantics.
- `policy/scope-boundaries.md`: technical-only scope and active folder/reference boundaries.
- `policy/metadata-frontmatter-indexes.md`: frontmatter, processed metadata, JSONL indexes, sidecars, and naming.
- `policy/graph-retrieval.md`: Obsidian graph semantics and retrieval order.
- `policy/validation-audit.md`: support files, validation gates, audit checks, and success conditions.
- `policy/token-budgets.md`: page, chunk, retrieval, and batch budgets.
- `policy/implementation-boundary.md`: separation between RENO and live implementation repositories.
- `policy/anti-patterns.md`: working-mode constraints and forbidden patterns.

## Templates

- `templates/source-page-template.md`: source page shape and source-page rules.
- `templates/concept-page-template.md`: concept page shape and concept-page rules.

## Support Directories

- `prompts/`: execution prompts.
- `structured/schema/`: schema enforcement artifacts.
- `scripts/`: validation, indexing, and audit scripts.

## Archive

- `archive/AGENTS.monolith.before-split.md` is an audit-only copy of the pre-split root file. It is not active policy.
