# USE method

- Tag: heuristic

## Definition

The **utilization, saturation, and errors (USE) method** is a resource-oriented performance methodology:

For every resource, check **utilization**, **saturation**, and **errors**.

## Relation

- Role: method (resource-oriented checklist used early to screen for bottlenecks).
- A fast screening method to identify likely systemic bottlenecks (ties directly to [[utilization-and-saturation]]).
- Iterating resources before tools aims for coverage and makes gaps explicit as [[known-unknowns-framework]].
- Complements [[resource-analysis-vs-workload-analysis]]: USE is primarily a resource-analysis technique, often used early.
- Fits [[model-classify-intervene]] by providing a consistent classification lens for “what’s constrained” before interventions.
