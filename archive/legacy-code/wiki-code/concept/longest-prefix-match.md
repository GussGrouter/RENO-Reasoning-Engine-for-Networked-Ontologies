# Longest prefix match

- Tag: mechanism

## Definition

**Longest prefix match (LPM)** selects, among all matching prefixes, the match with the greatest prefix length (most specific match).

## Scope note

This is a general selection rule for hierarchical/aggregated namespaces where “more specific overrides less specific”.

## Relation

- Used in routing/forwarding lookups; constrains lookup data-structure choices.
- Fits into [[network-algorithmics]] as an example of an implementation-critical lookup rule.
