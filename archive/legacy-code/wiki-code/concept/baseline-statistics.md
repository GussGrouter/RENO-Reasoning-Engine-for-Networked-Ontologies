# Baseline statistics

- Tag: heuristic

## Definition

**Baseline statistics** are recorded “normal” measurements (collected periodically and/or before/after changes) used as a reference to judge whether current behavior is unusual.

## Relation

- Role: method (a repeatable measurement routine that supports change comparison and anomaly suspicion).
- Complements [[counters-statistics-metrics]] and monitoring dashboards by providing historical reference when a metric is unfamiliar or not already trended.
- Fits [[model-classify-intervene]] by enabling “classify” (is this normal?) before interventions.
