# Quantifying performance gains

- Tag: heuristic

## Definition

**Quantifying performance gains** estimates and compares the expected improvement from potential fixes (via observation or experimentation) using a reliable metric, so fixes can be prioritized.

## Relation

- Role: method (a decision procedure for prioritizing work based on expected impact).
- Observation-based estimates often decompose latency into synchronous components (see [[latency-analysis]] and [[throughput-latency-metrics]]).
- Fits [[model-classify-intervene]] by turning proposed interventions into comparable, quantified expected gains before committing effort.
