# RED method

- Tag: heuristic

## Definition

The **request rate, errors, and duration (RED) method** is a service-oriented monitoring methodology:

For every service, check **request rate**, **errors**, and **duration**.

## Relation

- Role: method (service-focused checklist; complements machine-level screening in [[use-method]]).
- A user-perspective “service health” complement to the machine-perspective [[use-method]].
- Request rate + duration patterns help separate load-driven vs architecture-driven explanations (connects to [[resource-vs-implementation-bottleneck]]).
- Fits [[model-classify-intervene]] by making “classify first” concrete for services: load vs architecture clues before interventions.
