# Known-unknowns framework

- Tag: abstraction

## Definition

The **known-unknowns framework** classifies what you do and don’t know during performance work:

- **known-knowns**: signals you know to check and have already observed
- **known-unknowns**: signals/subsystems you know exist but have not yet observed
- **unknown-unknowns**: important factors you are not checking because you do not know they exist

## Relation

This provides a diagnosis orientation: expand unknown-unknowns into known-unknowns by learning system components and adding observability, then reduce known-unknowns by measuring.
