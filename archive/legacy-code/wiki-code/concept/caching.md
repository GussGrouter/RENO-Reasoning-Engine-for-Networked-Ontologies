# Caching

- Tag: mechanism

## Definition

**Caching** stores results or data from a slower tier in a faster tier to reduce repeated expensive accesses.

## Scope note

Caches can be multi-level and exist in hardware and software. Their effectiveness depends on locality and cache management policies.

## Relation

Caching is a common way to trade memory/space for latency and throughput improvements (see [[time-space-tradeoff]]).
