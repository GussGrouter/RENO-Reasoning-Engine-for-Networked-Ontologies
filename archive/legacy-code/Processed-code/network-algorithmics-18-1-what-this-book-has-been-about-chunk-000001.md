18.1 What this book has been about
The main problem considered in this book is bridging the performance gap between good network
abstractions and fast network hardware. Abstractions, such as modular server code and prefix-based
forwarding, make networks more usable, but they also exact a performance penalty when compared to
the capacity of raw transmission links, such as optical fiber. The central question tackled in this book
