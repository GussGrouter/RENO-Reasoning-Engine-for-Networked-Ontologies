There are many, many more counters, especially for newer processors.
Another processor detail to be aware of is how many hardware counter registers it provides. For
example, the Intel Skylake microarchitecture provides three fixed counters per hardware thread,
and an additional eight programmable counters per core (“general-purpose”). These are 48-bit
counters when read.
For more examples of PMCs, see Table 4.4 in Section 4.3.9 for the Intel architectural set.
Section 4.3.9 also provides PMC references for AMD and ARM processor vendors.
