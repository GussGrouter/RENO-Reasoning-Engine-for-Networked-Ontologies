Observability Tools

previous section for methodologies to follow when using them.

This is a selection of tools and capabilities to support Section 7.4, Methodology. We begin with
tools for system-wide memory usage statistics and then drill down to per-process and allocation
tracing. Some of the traditional tools are likely available on other Unix-like operating systems
where they originated, including: vmstat(8), sar(1), ps(1), top(1), and pmap(1). drsnoop(8) is a
BPF tool from BCC (Chapter 15).
See the documentation for each tool, including its man pages, for full references on its features.
