# Systems Performance — Ch.10 §10.5.5 Performance monitoring (key metrics)

Source: `systems-performance-ch10-scout-p520-640.txt`, lines **2260–2278** (PDF 520–640 extract; scout rebuilt 2026-04-20).

## Summary

- Monitoring finds active issues and time patterns (daily users, scheduled backups).
- Key metrics:
  - throughput (bytes/s) per interface and direction
  - connections/s
  - errors/drops
  - retransmits and out-of-order
- If bandwidth limits exist, monitor imposed-limit stats too.
