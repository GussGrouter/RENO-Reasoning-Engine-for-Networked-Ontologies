6.3.15

Compiler Optimization

The CPU runtime of applications can be significantly improved through compiler options
(including setting the word size) and optimizations. Compilers are also frequently updated to take
advantage of the latest CPU instruction sets and to implement other optimizations. Sometimes
application performance can be significantly improved simply by using a newer compiler.
This topic is covered in more detail in Chapter 5, Applications, Section 5.3.1, Compiled
Languages.
