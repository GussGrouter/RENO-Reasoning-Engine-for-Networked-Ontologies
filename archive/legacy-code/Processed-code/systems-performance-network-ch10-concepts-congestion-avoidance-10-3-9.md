# Systems Performance — Ch.10 §10.3.9 Congestion avoidance (shared resource behavior)

Source: `systems-performance-ch10-scout-p520-640.txt`, lines **1261–1277** (PDF 520–640 extract; scout rebuilt 2026-04-20).

## Summary

- Networks are shared and can become congested; congestion can cause drops and retransmits (latency).
- Both network devices and hosts can drop packets under high load.
- Congestion avoidance mechanisms exist across layers (Ethernet pause, IP ECN, TCP congestion windows/algorithms).
