# Systems Performance — Ch.10 §10.3.8 Interface negotiation (speed/duplex)

Source: `systems-performance-ch10-scout-p520-640.txt`, lines **1242–1260** (PDF 520–640 extract; scout rebuilt 2026-04-20).

## Summary

- Interfaces may autonegotiate operational mode with the peer (e.g., bandwidth and duplex).
- Autonegotiation can downshift due to peer capability or physical problems (bad wiring).
- Full duplex allows simultaneous bidirectional transmission; half duplex does not.
