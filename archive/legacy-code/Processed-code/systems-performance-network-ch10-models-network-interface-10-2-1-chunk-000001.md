# Systems Performance — Ch.10 §10.2.1 Network interface (model)

Source: `systems-performance-ch10-scout-p520-640.txt`, lines **925–938** (PDF 520–640 extract; scout rebuilt 2026-04-20).

## Summary

- A **network interface** is an OS endpoint abstraction mapped to a physical port (TX/RX channels).
- Treat it as a configurable boundary for performance claims (per-interface throughput/latency is meaningful).
