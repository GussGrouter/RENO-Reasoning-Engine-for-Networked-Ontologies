# Systems Performance — Ch.10 §10.3.1 Networks and routing

Source: `systems-performance-ch10-scout-p520-640.txt`, lines **999–1036** (PDF 520–640 extract; scout rebuilt 2026-04-20).

## Summary

- Networks are segmented for scalability; routing moves packets across networks.
- Shared network components (routers/switches) introduce **contention**: unrelated traffic can hurt performance.
- Unicast vs multicast differ; cloud environments may block multicast.
- Firewalls add policy boundaries that can change reachable paths.
